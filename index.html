MONK-1

Twelve singers for the M-VAVE FM-1

MonkSynth's singing voice on the FM-1, with the twelve characters of its iOS port, from a monk to a slice of pizza, each on its own stage, its mouth following the vowel. Velocity sets the level and aftertouch moves the vowel, read from the FM-1's own keys with no changes to the hardware.

Try it in the browserThe same code the FM-1 runs, with sound. Click lower on a key for more velocity; drag down for aftertouch. Works from the keyboard too. Install v0.9.1From Chrome or Edge, with the FM-1 connected by USB. Nothing to install on the computer. ManualGetting started in a few minutes, then everything else. Download monk-0.9.1.fwscFor the command-line installer: python3 tools/fm1_install.py monk-0.9.1.fwsc SourceGitHub, GPL-3.0. Built on Felucca by Hügelton Instruments.

What it does

  • Twelve singers. Jerry the monk, Guppo, Philip, Suze, Gerald, Bess, EeOo, Snider, Fipsy, Peppo, Marley and Razor, each with its own voice, each remembering your changes.
  • Velocity sets the note's level, read from the FM-1's own keys.
  • Aftertouch moves the vowel, bends the pitch, or both, counted from where the key rests.
  • The voice. MonkSynth's formant synthesis: vowel, head size, breath, glide, a choir of up to ten, vibrato, echo and an envelope, four knobs a page.
  • MIDI. Notes with velocity and polyphonic aftertouch out over USB; notes, aftertouch and the vowel in.
